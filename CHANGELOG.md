# Changelog · Список изменений

All notable changes to Deskplot are documented here.
Здесь фиксируются все значимые изменения Deskplot.

## [2.0.2](../../releases/tag/v2.0.2) — 2026-09-20

**English**
- Uninstalling now also removes the fence folders once they are empty, so nothing is left behind.

**Русский**
- При удалении программы опустевшие папки заборов теперь тоже убираются — ничего лишнего не остаётся.

## [2.0.1](../../releases/tag/v2.0.1) — 2026-09-20

**English**
- **Move everything back to the desktop**: a button in Settings → Sorting returns the contents of all fences to the desktop, with a preview and undo.
- Uninstalling now does this **automatically**, so files are never left behind in fence folders. You can turn it off in Settings → Sorting.
- Fixed: the program crashed on start right after creating the fences — no tray icon, settings, shortcuts or updates (2.0.0).
- Fixed: the error log could not be written on a clean install, which hid such failures.

**Русский**
- **«Вернуть всё на рабочий стол»**: кнопка в «Настройки → Раскладка» возвращает содержимое всех заборов на рабочий стол, с предпросмотром и отменой.
- При удалении программы это теперь происходит **автоматически**, чтобы файлы не остались забытыми в папках заборов. Отключается в «Настройки → Раскладка».
- Исправлено: программа падала при запуске сразу после создания заборов — не было ни значка в трее, ни настроек, ни горячих клавиш, ни обновлений (2.0.0).
- Исправлено: на чистой установке не записывался журнал ошибок, из-за чего такие сбои оставались незаметными.

## [2.0.0](../../releases/tag/v2.0.0) — 2026-09-20

First public release · Первый выпуск.

**English**
- Fences: translucent containers on the desktop, each showing its own folder; 7 themes, docking to screen edges, expand on hover.
- Organize desktop: preview the plan, sort by extension, name mask, size, age or program type — and undo any sort.
- Programs by category: games, launchers, editors, development, browsers, chat, office, utilities.
- Quick launch (Ctrl+Alt+Space), search across fences, global shortcuts, export/import of settings.
- English and Russian interface, a short tour on first launch, automatic updates.

**Русский**
- Заборы: полупрозрачные контейнеры на рабочем столе, у каждого своя папка; 7 тем, прижатие к краю экрана, разворот при наведении.
- «Разложить рабочий стол»: сначала план, раскладка по расширению, маске имени, размеру, возрасту и типу программы, любую раскладку можно отменить.
- Программы по категориям: игры, лаунчеры, редакторы, разработка, браузеры, общение, офис, утилиты.
- Быстрый запуск (Ctrl+Alt+Space), поиск по заборам, глобальные сочетания, экспорт и импорт настроек.
- Интерфейс на русском и английском, короткое обучение при первом запуске, автообновление.
